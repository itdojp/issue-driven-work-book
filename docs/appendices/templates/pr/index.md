## 記入例（抜粋）

```md
## 何を

- 入力フォームの必須項目チェックを追加し、エラー文言を具体化

## なぜ

- 直近2週間で「未入力のまま保存」起因の問い合わせが増加（誤操作率 5%→1% 以下へ低減したい）

## 影響

- 影響範囲: 入力フォームの保存処理（API/DBスキーマ変更なし）
- リスク: 既存の自動入力が弾かれる可能性（境界条件をテストで確認）

## テスト

- 単体: 必須項目/境界値のバリデーション
- E2E: 主要導線（作成→保存→エラー表示→再保存）

## 受け入れ条件との対応

|Issueの受け入れ条件|対応する変更|確認結果|残タスク|
|---|---|---|---|
|必須項目が未入力なら保存されない|APIバリデーション追加|単体/E2E PASS|なし|
|不足項目が分かる|項目別のエラー文言を返す|画面確認 PASS|全画面の文言統一は別Issue|

## レビュー観点

- 破壊的変更が無いこと（API/DB）
- エラー表示の文言と運用影響
- suggestion は採用可。ただし文言ポリシー全体統一は別Issueに分離

## ロールバック

- Feature flag をOFFにする（設定手順をRunbookに記載）

## 関連Issue

- #123

## レビュー対応メモ

- review 本文: 全件確認
- inline comment / suggestion: 修正または対応不要理由を返信
- 未解決 thread: 0 を確認してから merge
```
