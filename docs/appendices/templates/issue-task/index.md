## 記入例（抜粋）

- 背景: 監視アラートが誤検知しており当番負荷が上がっている（直近7日で誤検知15回、例）
- 目的: p95 レイテンシのアラート条件を見直し、誤検知を減らす
- スコープ: production の `api-latency-p95` アラート（しきい値/期間/通知先）
- 非スコープ: 監視基盤の刷新、全アラートの一括見直し
- 手順: 1) 現状のメトリクス分布を確認 2) しきい値案を作成 3) ステージングで検証 4) 本番反映
- 期待結果: 反映後1週間で誤検知が 15回→3回以下（例）、重大アラートの見逃しが増えない
- 確認方法: しきい値変更 PR、ステージング検証ログ、反映後1週間のアラート履歴
- ロールバック: 旧しきい値に戻す / 通知先を一時停止（条件を明記）
- 完了条件: Runbook のアラート説明を更新し、変更 PR / 反映日時を相互リンクする
- 根拠・未確定点: 監視ログを根拠にする。繁忙期の分布は未確認のため再確認条件に入れる
