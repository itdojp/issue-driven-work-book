# DoR/DoD テンプレ

## Definition of Ready（入口条件）

- [ ] 背景/目的が書かれている
- [ ] スコープ/非スコープが書かれている
- [ ] 受け入れ条件がある
- [ ] 受け入れ条件ごとの確認方法がある
- [ ] 根拠と未確定点が分離されている
- [ ] 依存関係/リスクが整理されている

## Definition of Done（出口条件）

- [ ] 受け入れ条件を満たす
- [ ] PR body に変更範囲、確認結果、リスク、ロールバックを記載した
- [ ] review 本文・inline comment・suggestion を全件確認し、修正または対応不要理由を返信した
- [ ] 未解決 review thread が 0 である
- [ ] CI が green である
- [ ] merge 後の main checks と公開反映を確認した
- [ ] ロールバックが定義されている
- [ ] 運用/FAQ/Runbook へ転記済み（必要に応じて）

## 運用メモ

- DoR を満たせない場合は、着手しない理由ではなく「不足情報をいつ誰が埋めるか」として管理する
- DoD を満たせない項目は、未完了のまま閉じず、follow-up Issue として分離する
- レビュー対応は、修正だけでなく「対応しない判断」も返信して証跡に残す
